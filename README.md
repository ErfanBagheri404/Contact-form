# Contact form

![Design preview for the Contact form challenge](./design/desktop-preview.jpg)

Solution to the Frontend Mentor **Contact form** challenge - a responsive form built from the provided design.

**Live demo:** https://erfan-revenant.github.io/Contact-form/

## Built with

- Semantic HTML5
- CSS custom properties, Flexbox and media queries
- Vanilla JavaScript for the interactive behaviour (no framework, no build step)
- Bundled webfonts and SVG assets from the challenge starter files

## Run locally

```bash
git clone https://github.com/ErfanBagheri404/Contact-form.git
cd Contact-form
```

Open `index.html` in a browser. Nothing to install or compile.
